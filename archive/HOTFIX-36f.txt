Why the latest managed smoke test failed
----------------------------------------
The build itself has already moved off the old spike-only invocation.

However, the managed source-contract smoke test still required this historical
literal to exist in Build-LocalRemoteTest.ps1:

  EnableRemoteMonitorSpike=true

Hotfix 36 deliberately removed that explicit spike-only build property from the
normal v1.2 path, so the test was now checking for behavior we intentionally no
longer want.

Fix
---
Replace that stale assertion with the current production-candidate contract:
- normal v1.2 personal-stable build banner exists;
- windows-x64-release is the normal native preset;
- managed smoke dependencies are rebuilt with --no-incremental.

No product/runtime behavior changes.

Apply
-----
Extract into the GrassiBoard repository root and overwrite files.

Do NOT rerun any Apply/Reset scripts.

Then run only:

powershell -ExecutionPolicy Bypass -File .\tools\Build-LocalRemoteTest.ps1 -Run -RunSmokeTests
