GrassiBoard v1.2.0 — Hotfix 36
Personal-Stable Production Candidate

This patch promotes the fully accepted v1.2 Remote Monitor implementation from
the old spike-only build gate into the NORMAL v1.2 build path for the user's
current private/personal use.

IMPORTANT
---------
Because the live repository contains several v1.1/v1.2 files that were created
before this chat and are newer than the original repository snapshot, Hotfix 36
does NOT overwrite those live project/installer/workflow files blindly.

After extracting the ZIP into the repository root, run the included migration
script once. It validates the already-working live App.csproj before changing
metadata.

APPLY
-----
1. Extract this ZIP into the GrassiBoard repository root and overwrite files.
2. Run:

powershell -ExecutionPolicy Bypass -File .\tools\Apply-Hotfix36-V12PersonalStable.ps1

3. Build the NORMAL v1.2 path (no -RemoteMonitorSpike):

powershell -ExecutionPolicy Bypass -File .\tools\Build-LocalRemoteTest.ps1 -Run -RunSmokeTests
