GrassiBoard — READ ME FIRST
===========================

This file travels with the portable Windows x64 package.

1. Extract the entire ZIP to a normal writable folder. Do not run GrassiBoard.exe from inside the ZIP.
2. Keep the known-working external virtual audio cable (VB-CABLE or another compatible paired cable) installed. GrassiBoard does not install or replace a custom audio driver.
3. Run GrassiBoard.exe.
4. In Routing, choose the physical Windows microphone or the accepted Phone Mic path as appropriate, and keep the Program output pointed at the external virtual-cable render endpoint.
5. Existing Voice FX, Soundboard, Media, Remote Control, Remote Monitor and Phone Mic behavior must remain unchanged while GrassiLooper is under development.

GrassiLooper v1.4 development note
---------------------------------
Builds from feature/grassilooper-v1.4 are gated development/test builds. They must not be treated as a replacement for the frozen v1.3 personal-stable baseline until all GrassiLooper Gates are completed and explicitly accepted.

Gate 1 adds only the Looper UI/project/waveform/import-and-trim foundation. It does not add the realtime Looper transport or microphone recording engine yet.

For project status and acceptance boundaries, see docs/looper-development-status.md in the source repository.
